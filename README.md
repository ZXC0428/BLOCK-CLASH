# BLOCK CLASH

一款以瀏覽器執行的雙人方塊對戰遊戲。玩家需要控制方塊、消除完整的行，並透過攻擊行干擾對手，先讓對手失去戰鬥能力即可取得勝利。

## 專案資訊

- **專案名稱：** BLOCK CLASH
- **遊戲類型：** 方塊益智、雙人對戰
- **執行方式：** 純前端瀏覽器遊戲
- **目前版本：** B5
- **主要語言：** HTML、CSS、JavaScript
- **遊戲特色：** 單人練習、雙人對戰、多種盤面地圖、攻擊行、連擊與 KO 判定

## 遊戲功能

- 經典方塊下落與消行玩法
- 單人模式與雙人對戰模式切換
- 多種起始盤面：
  - 經典模式
  - 峽谷模式
  - 階梯模式
  - 分裂模式
- 消除多行時可產生攻擊行
- 連續消行可累積連擊效果
- 雙人對戰 KO 與勝負判定
- 分數、消除行數、攻擊行、連擊與待處理攻擊行顯示
- 120 秒遊戲倒數
- 支援桌面鍵盤與觸控操作
- 響應式介面，可在不同螢幕尺寸下遊玩

## 操作方式

### 單人模式

| 操作 | 按鍵 |
| --- | --- |
| 左移 | `←` |
| 右移 | `→` |
| 加速下落 | `↓` |
| 旋轉 | `↑` |
| 直接落下 | `Space` |

### 雙人模式

| 玩家 | 左移 | 右移 | 加速下落 | 旋轉 | 直接落下 |
| --- | --- | --- | --- | --- | --- |
| P1 | `←` | `→` | `↓` | `↑` | `Space` |
| P2 | `A` | `D` | `S` | `W` | `Shift` |

其他操作：

- `Enter`：開始遊戲或暫停遊戲
- `R`：重新開始
- 觸控裝置可使用畫面下方的操作按鈕

## 開始遊戲

本專案不需要安裝額外套件或建置工具。

1. 下載或複製本專案。
2. 使用瀏覽器開啟 `index.html`。
3. 點擊開始按鈕即可遊玩。

若瀏覽器限制本機檔案的部分功能，也可以使用任意靜態檔案伺服器啟動專案，例如：

```bash
python -m http.server 8000
```

接著開啟 `http://localhost:8000`。

## 專案結構

```text
.
├── index.html   # 遊戲畫面、介面與主要遊戲邏輯
├── style.css    # 視覺樣式與響應式版面
└── game.js      # 遊戲邏輯檔案
```

目前遊戲邏輯主要寫在 `index.html` 內嵌的 JavaScript 中，`game.js` 保留作為遊戲邏輯整理與拆分使用。
